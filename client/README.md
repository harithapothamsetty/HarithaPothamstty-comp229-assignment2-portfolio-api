# Haritha Pothamsetty Portfolio

A responsive personal portfolio website built with React and Vite.

## Features

- Six portfolio pages: Home, About, Projects, Education, Services, and Contact
- Custom HP logo and responsive navigation
- Professional About page with profile photo and downloadable resume
- Three project cards with visual images, descriptions, roles, and outcomes
- Contact form with confirmation feedback and redirect to the Home page
- Responsive layout for desktop, tablet, and mobile screens

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Run Locally

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
