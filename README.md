## Project Overview

This project is a full-stack portfolio application built with:

- React frontend
- Node.js and Express backend
- MongoDB database with Mongoose
- REST API CRUD operations
- JWT authentication and protected routes

## Run the Project Locally

1. Install dependencies.
2. Add required environment variables in a private `.env` file.
3. Start the backend server.
4. Start the React frontend from the `client` folder.
